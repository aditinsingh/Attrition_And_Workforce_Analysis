# Attrition_And_Workforce_Analysis

Interactive Employee Attrition Analysis Dashboard built in Microsoft Excel using PivotTables, Pivot Charts, KPIs and Slicers.

## 📊 Project Overview

This project analyzes employee attrition and workforce-related metrics using an interactive Excel dashboard.

The dashboard provides insights into employee attrition, income, tenure, overtime, and other workforce characteristics.

## 📌 Dashboard Features

- Total Employees
- Attrition Rate
- Employees Left
- Average Income
- Average Tenure
- Attrition analysis by department
- Attrition analysis by job role
- Attrition by overtime
- Interactive slicers
- PivotTables and Pivot Charts
